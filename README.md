# Crap-Counter

Broken Sling carp-counter app.

Live app: [GitHub Pages](https://focsaneanuionutbogdan18111989-spec.github.io/Crap-Counter/)

Open [index.html](index.html) in a browser to run the app. Session data is stored in browser local storage.

The soak timer requests browser notification permission when started. Alerts require the browser to keep the app running; Excel export loads SheetJS from its CDN and needs an internet connection.
